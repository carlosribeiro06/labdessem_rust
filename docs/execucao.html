Execucao

Como o estudo e configurado e resolvido

O comportamento do modelo e controlado pelo `study_config.json`. Aqui ficam o caminho do caso, os modos de execucao e os principais flags de formulacao.

Ver saidas Ver restricoes

Comando padrao

cargo run -p labdessem-cli

cargo run -p labdessem-cli -- crates/labdessem-io/study_config.json

opcao_execucao = 1

Fluxo iterativo completo: `LP -> MILP -> LP-FIXED -> LP-CALC-CMO`. Quando a rede esta ativa, os cortes de fluxo sao adicionados apenas para pares linha-periodo violados.

opcao_execucao = 2

Resolve um MILP unico. Com `rede = 1`, as restricoes de fluxo entram diretamente no modelo desde o inicio.

UCT

Ativa ou desativa o commitment termico: binarias de estado, startup, shutdown, TON, TOFF e rampas termicas.

UCH

Ativa ou desativa as variaveis binarias de compromisso hidraulico que canalizam a geracao por unidade.

FPHA

Seleciona entre os cortes da FPHA e a formulacao agregada por produtibilidade da usina.

TON_Residual

Ativa o tratamento de custo residual termico fora do horizonte e as colunas correspondentes nas saidas termicas.
