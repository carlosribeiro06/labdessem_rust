# Future Cost Function

This document describes the Future Cost Function (FCF) implementation in labdessem.

## Overview

The Future Cost Function represents the expected cost-to-go from the end of the scheduling horizon. It is implemented as a set of Benders cuts that linearize the value function from a stochastic dual dynamic programming (SDDP) solution.

When `FCF = 1` in `study_config.json`, the model reads cuts from `OPER_FCF.bin` and adds them as constraints that link the final reservoir volumes to the future cost variable.

## Mathematical Formulation

Each Benders cut defines a lower bound on the future cost as a function of final volumes:

```
future_cost ≥ intercept + Σ(coefficient[i] × final_volume[i])
```

Where:
- `future_cost` = scalar variable representing expected cost-to-go
- `intercept` = cut intercept (constant term)
- `coefficient[i]` = marginal value of water for hydro plant i
- `final_volume[i]` = volume at end of horizon for hydro plant i

The cut coefficients are typically the water value (dual of the water balance) from the SDDP backward pass.

## Binary File Format

The FCF binary file (`OPER_FCF.bin`) uses FlatBuffers serialization format.

### Structure

```
StageCuts (root table)
├── stage_id: u32
└── cuts: [Cut]
        ├── cut_id: u64
        ├── slot_index: u32
        ├── iteration: u32
        ├── forward_pass_index: u32
        ├── intercept: f64
        ├── coefficients: [f64]  (one per hydro plant)
        └── is_active: bool
```

### Cut Fields

| Field | Type | Description |
|-------|------|-------------|
| `cut_id` | u64 | Unique cut identifier |
| `slot_index` | u32 | Slot position in original model |
| `iteration` | u32 | SDDP iteration when cut was generated |
| `forward_pass_index` | u32 | Forward pass scenario index |
| `intercept` | f64 | Cut intercept (π₀) |
| `coefficients` | [f64] | Water value coefficients (π) |
| `is_active` | bool | Whether cut is active in current solution |

## Implementation

### Reading Cuts

The file is parsed using a custom FlatBuffers reader in `read_future_cost_cuts()`. The reader:

1. Validates the file has minimum size (8 bytes)
2. Reads the root table offset
3. Parses the stage table to get stage ID and cuts vector
4. For each cut, extracts all fields including the coefficient array

### Adding to Model

When FCF is enabled, constraints are added in `build_future_cost_constraints()`:

```rust
for cut in system.future_cost_cuts {
    // future_cost ≥ intercept + Σ(coef[i] × volume[i])
    model.add_constraint(
        future_cost - Σ(coef[i] × final_volume[i]) ≥ intercept
    );
}
```

### Objective Integration

The future cost variable is added to the objective function with coefficient 1.0, meaning the model minimizes:

```
total_cost = operational_cost + future_cost
```
