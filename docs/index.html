Architecture

Separation of concerns from domain to simulation

The workspace is divided into focused crates so the project can evolve with strong boundaries between data modeling, optimization, IO, solver integration, and execution.

labdessem-core

Domain structures, identifiers, validations, generation assets, reservoirs, buses, lines, and submarkets.

labdessem-model

Variables, constraints, objective function, indexing, and solve modes for LP, MILP, and LP-fixed.

labdessem-io

Study reader driven by a JSON configuration file pointing to a case path with CSV data.

labdessem-solver

Optimization backend integration through good_lp with a HiGHS-oriented setup.

labdessem-simulation

Iterative orchestration, DC flow evaluation, flow-cut accumulation, and CSV result export.

labdessem-cli

Runtime entrypoint with progress logging, case loading, simulation execution, and output reporting.

Methodology

Mathematical formulation, decision variables, and constraint system

The current codebase already contains a concrete mathematical model with CSV-driven data, three solve modes, commitment logic, hydro balance, operational limits, PTDF network cuts, infeasibility slacks, and residual-cost accounting for thermal startups.

Sets and Indexes

  • \(t \in T\): study periods
  • \(s \in S\): submarkets
  • \(b \in B\): buses
  • \(l \in L\): transmission lines
  • \(i \in U^{th}\): thermal units
  • \(j \in U^{hy}\): hydro units
  • \(h \in H\): hydro plants
  • \(w \in W\): wind plants
  • \(q \in Q\): solar plants
  • \((s,r) \in I\): directed submarket interchange pairs

Solve Modes

  • LP: continuous dispatch with no commitment logic
  • MILP: thermal and hydro commitment constraints activated
  • LP-FIXED: commitment copied from MILP and fixed for polishing

Network cuts are discovered iteratively around this solve stack. Time data such as TON, TOFF, and Tinic are read in hours and converted internally to periods using \( \left\lceil \frac{\text{hours}}{\Delta t} \right\rceil \).

Decision Variables

Thermal

  • \(G^{th}_{i,t}\): thermal generation
  • \(u^{th}_{i,t}\): on/off commitment
  • \(y^{th}_{i,t}\): thermal startup variable with \(0 \le y \le 1\)
  • \(w^{th}_{i,t}\): thermal shutdown binary

Hydro

  • \(G^{hy}_{j,t}\): hydro generation by unit
  • \(Q_{j,t}\): turbining by hydro unit
  • \(V_{h,t}\): reservoir volume by plant
  • \(S_{h,t}\): spillage by plant
  • \(u^{hy}_{j,t}\): hydro commitment
  • \(su^{hy}_{j,t}\): hydro startup binary
  • \(sd^{hy}_{j,t}\): hydro shutdown binary

Renewable and System

  • \(G^{w}_{w,t}\): wind generation
  • \(G^{q}_{q,t}\): solar generation
  • \(INT_{s,r,t}\): directed interchange
  • \(DEF_{s,t}\): demand deficit by submarket
  • \(\sigma^{flow}\): network slack for infeasible flow cuts
  • \(\sigma^{lim}\): slack for infeasible operational limits

Objective Function

\[ \min Z = \sum_{t}\sum_{i \in U^{th}} c^{var}_{i}\,\Delta t\,G^{th}_{i,t} + \sum_{t}\sum_{s \in S} c^{def}_{s}\,\Delta t\,DEF_{s,t} + \sum_{t}\sum_{h \in H} c^{spill}_{h}\,S_{h,t} \] \[ \qquad + \sum_{t}\sum_{(s,r)\in I} c^{int}_{s,r}\,\Delta t\,INT_{s,r,t} + \sum_{t}\sum_{i \in U^{th}} \left(c^{start}_{i}\,y^{th}_{i,t} + c^{stop}_{i}\,w^{th}_{i,t}\right) \] \[ \qquad + \sum_{t}\sum_{j \in U^{hy}} \left(c^{start}_{j}\,su^{hy}_{j,t} + c^{stop}_{j}\,sd^{hy}_{j,t}\right) \] \[ \qquad + \sum_{t}\sum_{i \in U^{th}} y^{th}_{i,t}\,GT^{pos}_{i}\,\max\{CVU_i-\pi_{s(i)},0\}\,\Delta t \]

The residual thermal term is activated only when the TON_Residual flag is on. In the current implementation, the thermal startup and shutdown costs use the same \(y^{th}_{i,t}\) and \(w^{th}_{i,t}\) variables that appear in the ramp formulation, \(GT^{pos}_{i}\) is an aggregated post-horizon obligation built from the startup trajectory, the remaining minimum-up block at \(P^{min}\), and the shutdown trajectory of each thermal unit.

Demand Balance by Submarket

\[ \sum_{i \in s} G^{th}_{i,t} + \sum_{j \in s} G^{hy}_{j,t} + \sum_{w \in s} G^{w}_{w,t} + \sum_{q \in s} G^{q}_{q,t} + \sum_{r} INT_{r,s,t} - \sum_{r} INT_{s,r,t} + DEF_{s,t} = DEM_{s,t} \]

Demand satisfaction is enforced at the submarket level. Directed interchange variables close the balance across submarkets.

Thermal State Transition

For \(t = 1\)
\[ u^{th}_{i,1} - u^{ini}_{i} = y^{th}_{i,1} - w^{th}_{i,1} \]
For \(t > 1\)
\[ u^{th}_{i,t} - u^{th}_{i,t-1} = y^{th}_{i,t} - w^{th}_{i,t} \] \[ y^{th}_{i,t} + w^{th}_{i,t} \le 1 \qquad 0 \le y^{th}_{i,t} \le 1 \qquad w^{th}_{i,t} \in \{0,1\} \]

Hydro State Channeling

\[ u^{hy}_{j,t} - u^{hy}_{j,t-1} = su^{hy}_{j,t} - sd^{hy}_{j,t} \] \[ su^{hy}_{j,t} + sd^{hy}_{j,t} \le 1 \qquad su^{hy}_{j,t},\,sd^{hy}_{j,t} \in \{0,1\} \]

Hydro commitment currently uses binary startup and shutdown variables directly.

Thermal Operating Limits

LP
\[ 0 \le G^{th}_{i,t} \le P^{max}_{i} \]
MILP / LP-FIXED
\[ G^{th}_{i,t} \le P^{max}_{i}\,u^{th}_{i,t} \qquad G^{th}_{i,t} \ge P^{min}_{i}\,u^{th}_{i,t} \]

The pure upper bound exists directly in the variable domain. Commitment-enabled modes add minimum generation and unit-state coupling.

Hydro Operating Limits

\[ 0 \le Q_{j,t} \le Q^{max}_{j} \qquad S_{h,t} \ge 0 \qquad G^{hy}_{j,t} = prod_{j}\,Q_{j,t} \]
LP
\[ 0 \le G^{hy}_{j,t} \le P^{max}_{j} \]
MILP / LP-FIXED
\[ G^{hy}_{j,t} \le P^{max}_{j}\,u^{hy}_{j,t} \qquad G^{hy}_{j,t} \ge P^{min}_{j}\,u^{hy}_{j,t} \]

Thermal Ramp Formulation

\[ Y_{i,t} = \sum_{k=1}^{K_i^{up}} y^{th}_{i,t-k+1} \qquad TRUP_{i,t} = \sum_{k=1}^{K_i^{up}} a_{i,k}\,y^{th}_{i,t-k+1} \] \[ W_{i,t} = \sum_{k=1}^{K_i^{down}} w^{th}_{i,t+k} \qquad TRDN_{i,t} = \sum_{k=1}^{K_i^{down}} d_{i,K_i^{down}-k+1}\,w^{th}_{i,t+k} \] \[ G^{th}_{i,t} \ge P^{min}_{i}\left(u^{th}_{i,t} - Y_{i,t} - W_{i,t}\right) + TRUP_{i,t} + TRDN_{i,t} \] \[ G^{th}_{i,t} \le P^{max}_{i}\left(u^{th}_{i,t} - Y_{i,t} - W_{i,t}\right) + TRUP_{i,t} + TRDN_{i,t} \]

Startup and shutdown trajectories are read per thermal unit. Initial ramp states are represented explicitly by RupInic, RdownInic, and Tinic, with the remaining initial trajectory inferred from elapsed time in state.

Thermal Minimum Up / Down

\[ \sum_{s=t}^{t+\widehat{TON}_{i,t}-1} u^{th}_{i,s} \ge \widehat{TON}_{i,t}\left(u^{th}_{i,t} - u^{th}_{i,t-1}\right) \] \[ \sum_{s=t}^{t+\widehat{TOFF}_{i,t}-1} \left(1-u^{th}_{i,s}\right) \ge -\widehat{TOFF}_{i,t}\left(u^{th}_{i,t} - u^{th}_{i,t-1}\right) \]

The code also fixes the initial periods whenever the unit enters the horizon with remaining minimum up or minimum down obligation.

Hydro Minimum Up / Down

\[ \sum_{s=t}^{t+\widehat{TON}^{hy}_{j,t}-1} u^{hy}_{j,s} \ge \widehat{TON}^{hy}_{j,t}\left(u^{hy}_{j,t} - u^{hy}_{j,t-1}\right) \] \[ \sum_{s=t}^{t+\widehat{TOFF}^{hy}_{j,t}-1} \left(1-u^{hy}_{j,s}\right) \ge -\widehat{TOFF}^{hy}_{j,t}\left(u^{hy}_{j,t} - u^{hy}_{j,t-1}\right) \]

Hydro Balance

For \(t = 1\)
\[ V_{h,1} = V_{h,0} + INA_{h,1} + \sum_{m \in Up(h)} \left(Q_{m,1} + S_{m,1}\right) - \sum_{j \in h} Q_{j,1} - S_{h,1} \]
For \(t > 1\)
\[ V_{h,t} = V_{h,t-1} + INA_{h,t} + \sum_{m \in Up(h)} \left(Q_{m,t} + S_{m,t}\right) - \sum_{j \in h} Q_{j,t} - S_{h,t} \]

V_h,0 is the initial storage condition from the input data. The current formulation supports multiple upstream hydro plants in cascade.

Reservoir Bounds

\[ V^{min}_{h} \le V_{h,t} \le V^{max}_{h} \]

Hydro Productivity and Turbining Limits

\[ G^{hy}_{j,t} = prod_j \, Q_{j,t} \qquad 0 \le Q_{j,t} \le Q^{max}_{j} \qquad S_{h,t} \ge 0 \]

Directed Interchange Limits

\[ 0 \le INT_{s,r,t} \le LIM_{s,r} \]

Limits are directional, so the bound from s → r may differ from r → s.

User-Defined Operational Limits

\[ Linf_{u,x,t} \le X_{u,x,t} \le Lsup_{u,x,t} \]

The reader expands OPER_REST_LIM over its active horizon and validates compatibility between plant type and variable type. Supported targets include GER, VERT, VOL, TURB, and DEFLU = VERT + TURB.

Network Representation

The PTDF section is presented here in the same matrix form as your Julia implementation. One slack bus is removed from the formulation, and the reduced network matrices are built explicitly before computing the line-flow sensitivities.

Reduced nodal susceptance matrix
\[ B = \begin{bmatrix} \sum \dfrac{1}{x_l} & \cdots & -\dfrac{1}{x_l} \\ \vdots & \ddots & \vdots \\ -\dfrac{1}{x_l} & \cdots & \sum \dfrac{1}{x_l} \end{bmatrix} \]
Diagonal line susceptance matrix
\[ B_{diag} = \operatorname{diag}\left(\frac{1}{x_1}, \frac{1}{x_2}, \ldots, \frac{1}{x_{|L|}}\right) \]
Reduced incidence matrix
\[ A_{l,b} = \begin{cases} 1, & \text{if } b = \text{barra\_de}(l) \\ -1, & \text{if } b = \text{barra\_para}(l) \\ 0, & \text{otherwise} \end{cases} \]
PTDF matrix
\[ \beta = B_{diag}\,A\,B^{-1} \]
Load vector by period
\[ P_t = \begin{bmatrix} D_{2,t} & D_{3,t} & \cdots & D_{|B|,t} \end{bmatrix}^{\top} \]
Generation vector by period
\[ G_t = \begin{bmatrix} G_{2,t} & G_{3,t} & \cdots & G_{|B|,t} \end{bmatrix}^{\top} \]
Line flow vector
\[ F_t = \beta \left(G_t - P_t\right) \]

Therefore, for each line \(l\) and period \(t\), the flow is extracted from the vector \(F_t\) and compared against the thermal limit:

\[ -F^{max}_{l} \le f_{l,t} \le F^{max}_{l} \]

This is the same formulation pattern you showed in Julia: build \(B\), build \(B_{diag}\), build \(A\), build \(P_t\), build \(G_t\), and finally compute \(\beta = B_{diag}AB^{-1}\).

Flow-Cut Generation

For each violated \((l,t)\)
\[ f_{l,t} \le F^{max}_{l} \qquad f_{l,t} \ge -F^{max}_{l} \] \[ \sum_{i} \beta_{l,b(i)}\,G^{th}_{i,t} + \sum_{j} \beta_{l,b(j)}\,G^{hy}_{j,t} + \sum_{w} \beta_{l,b(w)}\,G^{w}_{w,t} + \sum_{q} \beta_{l,b(q)}\,G^{q}_{q,t} \le F^{max}_{l} + \sum_{b}\beta_{l,b}\,D_{b,t} \]

The flow expression is rewritten directly in terms of generation variables and the constant nodal demand shift, so only violated branch-period pairs produce additional constraints. If the network is infeasible after cuts are added, flow slack variables are introduced with a large penalty and recorded in dedicated infeasibility outputs.

Slack-Based Infeasibility Handling

\[ \text{flow cut upper} + \sigma^{flow,+}_{l,t} \le F_l^{max} \qquad \text{flow cut lower} - \sigma^{flow,-}_{l,t} \ge -F_l^{max} \] \[ X_{u,x,t} + \sigma^{lim,+}_{u,x,t} \le Lsup_{u,x,t} \qquad X_{u,x,t} - \sigma^{lim,-}_{u,x,t} \ge Linf_{u,x,t} \]

Whenever the constrained problem is infeasible, the simulation can rebuild the model with explicit slack variables for network cuts and operational limits, penalize them in the objective, and export structured infeasibility reports.

Iterative Resolution Strategy

  1. Solve the `LP`.
  2. Compute DC line flows.
  3. Detect violated line-period pairs.
  4. Add flow cuts only for the observed violations.
  5. Repeat until the LP becomes network-feasible.
  6. Solve the `MILP` with all accumulated cuts.
  7. Recompute flows on the MILP solution.
  8. If new violations appear, fix the integer decisions and solve `LP-FIXED` iteratively.
  9. Stop when no additional flow violations remain.

When the network flag is disabled, the simulation runs without PTDF construction or flow cuts. When it is enabled, the final reporting includes line flows, added cut lines, network infeasibilities, and iterative process statistics.

Workflow

Iterative network-constrained solution loop

The current process separates dispatch optimization from network violation discovery, adding line flow cuts only where they are actually required.

01

LP

Solve the relaxed dispatch problem without the full set of network cuts.

02

DC Flow

Compute line flows from nodal injections using the reduced susceptance model.

03

Violation Detection

Identify only the line-period pairs whose flows exceed thermal capacity.

04

Flow Cuts

Add upper and lower line limits only for the violated branch-period combinations.

05

MILP

Once the LP is network-feasible, solve the mixed-integer model with accumulated cuts.

06

LP-Fixed

If new violations appear, fix commitment decisions and polish the solution iteratively.

Modeling Scope

Generation, reservoirs, curtailment, and submarket balance

Thermal

Thermal plants contain units and support unit commitment-oriented modeling decisions.

Hydro

Hydro plants include groups, units, storage limits, initial volume, inflows, and cascades.

Renewables

Wind and solar are modeled at plant level with available generation and endogenous curtailment.

Network

Submarkets, buses, lines, linearized flows, and iterative flow restrictions shape system feasibility.

Outputs

Operational results exported as analysis-ready CSV files

Every completed run writes structured output files under <case_path>/RESULTADOS.

  • Hydro: unit and plant rows with volume, generation, turbining, and spillage
  • Thermal: generation, on/off state, residence times, residual time, and residual cost
  • Network: line flow, line limit, added cut lines, and violation flags
  • Wind: dispatched generation by period
  • Solar: dispatched generation by period
  • Limits: expanded operational limits and limit infeasibility reports
  • Process: iteration, objective, status, model size, and solve time per stage
