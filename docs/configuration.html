Configuration

Each study case requires a study_config.json file in its root directory. This file controls execution mode, model features, and solver behavior.

study_config.json

Example configuration:

{
  "$schema": "../../schemas/study_config.schema.json",
  "opcao_execucao": 2,
  "rede": 0,
  "UCT": 1,
  "UCH": 0,
  "TON_Residual": 0,
  "FPHA": "constant_productivity",
  "FCF": 1,
  "EngMax": 0
}

JSON Schema

A JSON Schema is provided at schemas/study_config.schema.json for IDE autocompletion and validation.

Add the $schema property to your config file:

{
  "$schema": "../../schemas/study_config.schema.json",
  ...
}

The schema path is relative to your study directory. Adjust the path based on your directory structure.

IDE Setup

VS Code

For automatic validation across all study configs, add to .vscode/settings.json:

{
  "json.schemas": [
    {
      "fileMatch": ["**/study_config.json"],
      "url": "./schemas/study_config.schema.json"
    }
  ]
}

Execution Mode

Value Description
1 Iterative: LP → MILP → LP-FIXED → LP-CALC-CMO
2 Single MILP solve

Mode 1 (Iterative): Starts with LP relaxation, solves MILP, then fixes integers and re-solves for dual information (CMOs). When network is enabled, adds DC flow cuts iteratively for violated line-period pairs.

Mode 2 (Single MILP): Direct mixed-integer solve. Faster but no dual information extraction.

Model Flags

Flag Type Description
rede 0/1 Enable DC network flow representation
UCT 0/1 Enable thermal unit commitment (binary variables)
UCH 0/1 Enable hydro unit commitment (binary variables)
TON_Residual 0/1 Enable thermal residual TON treatment at horizon end
FPHA string Hydro generation formulation: "constant_productivity", "precomputed", or "computed"
FCF 0/1 Enable future cost function (Benders cuts from OPER_FCF.bin)
EngMax 0/1 Enable dynamic maximum swallowing constraint (head-dependent turbining limits)

FPHA Flag

Controls how hydro generation is computed:

  • FPHA=1: Read FPHA cuts from OPER_FPHA.csv. Generation bounded by piecewise linear approximation.
  • FPHA=0: Generation = productivity × turbining. Simpler but less accurate for varying head.

FCF Flag

Controls future cost function:

  • FCF=1: Read Benders cuts from OPER_FCF.bin. Adds future cost variable and constraints linking final storage to expected future cost.
  • FCF=0: No future cost. Useful for deterministic single-stage studies.

EngMax Flag

Controls dynamic maximum swallowing (head-dependent turbining limits):

  • EngMax=1: Calculate net head from reservoir volume and tailrace polynomial, then apply the formula Q_max = Q_ef × (h_l / h_ef)^α where α depends on turbine type (0.5 for Francis, 0.2 for Kaplan). Requires CAD_GEOMETRIA_UHE.csv and CAD_TAILRACE.csv.
  • EngMax=0: Use static maximum turbining from registration data.

When geometry data is not available for a plant, EngMax falls back to the effective head from registration.
